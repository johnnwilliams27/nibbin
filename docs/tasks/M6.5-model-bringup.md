# M6.5 — Model Bring-Up

Status: ready to run after the M4+M5 gate is signed · Owner: Claude Code session at C:\Nibbin (solo milestone, main branch) · Human gate: John signs in LEARNINGS.md.

## Why this milestone exists

Six milestones deliberately built the rails before the trains: router, metering, budgets,
quarantine, injection defenses, runtime invariants, capture, redaction — all adversarially
gated at zero blast radius because nothing called a model yet. "LLM COGS $0.00 by
construction" in the gate log is a verification statement, not a product decision. The miss
was that model integration was never NAMED as a milestone — it was smeared implicitly across
M4 and M7 prep, which is how a working agent runtime shipped with no brain. This document
names it. M7 (user-zero study + Marketing Grove on product rails) is meaningless until real
drafts flow, so M6.5 blocks M7.

Architecture unchanged (SPEC §6.3): **T0** scripted/templated (no model) · **T1** cheap
model, ~80% of work (agent drafting, keeper chat beyond the scripted floor) · **T2**
frontier model, budgeted per user with transparent degradation (diagnosis generation,
complex drafts). Users never install a local model; the only local model is the Observer's
NER redaction sidecar (M6) — raw captures stay on device, only redacted derived content
reaches hosted models.
